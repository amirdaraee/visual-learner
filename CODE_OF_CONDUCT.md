# Code of Conduct

This project is for learning, so it should be a place where asking a basic question or pointing out a mistake feels safe.

## What we expect

- Be respectful and assume good faith.
- Give feedback on the work, not the person. Be specific and kind.
- Welcome beginners. No one needs to justify not knowing something.
- Credit other people's work.
- Accept correction gracefully, and give it gently.

## What is not acceptable

- Harassment, insults, discrimination or personal attacks.
- Sexualised language or imagery, and unwelcome attention.
- Publishing other people's private information.
- Spam, or promotion unrelated to the project.
- Anything else a reasonable person would call hostile in a learning space.

## Scope

This applies in issues, pull requests, discussions and any space where someone represents the project.

## Enforcement

Maintainers may edit or remove comments, close threads, or block people who break these rules. To report a problem, use GitHub's private "Report content" option on the comment, or open a private security advisory on the repository and mark it as a conduct report. Reports are handled confidentially.

This code of conduct is written in the spirit of the Contributor Covenant 2.1.
